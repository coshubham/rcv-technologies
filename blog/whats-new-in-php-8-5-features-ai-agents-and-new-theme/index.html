What’s New in PHP 8.5? Features, AI-Agents, and New Theme

RRCV Technologies January 27, 2026 4 min read

PhpStorm 2025.3 was released on November 20, 2025, with several key improvements. As of now, many developers have raised an issue regarding Git integration and Windows Subsystem for Linux.

The major highlight of this version is the new islands theme in the user interface that reduces visual clutter. In terms of functionality, pipe operator and AI integration are being seen as a crucial element.

As per the source, the Partial Function Application (PFA) is about to get improved by the next update that facilitates code reusability. However, let’s take a walkthrough on what improvements have been made while switching to PHP 8.5.

AI Integration

AI assistant now provides seamless flexibility, as you can switch between Junie and Claude in case one isn’t working. Now you can also view AI credits and the renewal date.

Another feature that is about to be rolled out is BYOK (Bring Your Own Key), allowing you to connect with your API key with OpenAI.

Islands Theme

With the new PhpStorm 2025.3, developers are getting the new Islands theme as part of the default look. There has been a major improvement with the editor, with clear separation between working areas.

As of now database will stop using the term query console, as they were stored in an obscure file and were hard to find. After merging the consoles and files, it makes editing file-based. The new query will be saved as Query_[N].sql, which can be customised in settings.

Streamlined MCP Server

MCP servers are now more advanced, as they automatically suggest enabling the servers when they are disabled. While launching mcp.json, PhpStorm will automatically fetch the data.

Laravel Support

As per the new version Laravel Idea Plugin is now bundled, facilitating seamless route, view, config, and translation without any setup. It also includes a pipe operator, array_first, and array_last.

  • Pipe operator ensures that the pipe code in PhpStorm is functioning correctly. (|>) takes the return value of the left size and passes it to the right side callable.
  • With the array parameter, developers can retrieve the first and last value in the element.
  • PHP 8.5 now lets you use closures in construct; as per the previous version, it was only accepted in constant expressions. Ensuring proper usage of closure as an attribute parameter.
  • The new version introduces #[NoDiscard], which helps in indicating that a function or return value cannot be ignored.

Other Noticeable Features

Now users can also clone the object with clone array with the clone () function.

When a code is treated with a _constructor and marked with final, it is treated like promoted properties. Similarly, some new add-on features include:

  • Asymmetric properties for static properties.
  • Attributes for a constant that declares a constant as its own statement.
  • PhpStorm 2025.3 provides Pest v4 support that includes the Continue Test Run button.
  • PhpStorm works with a cloud server as well. Enabling developers to connect to your AWS, Azure, and Google Cloud accounts.
  • The terminal tool gives you suggestions, option names, and path parameter names.

The only drawback is that it is still a paid product that costs $109 for the first year, and active subscribers have to pay $65.

Wrap Up

Earlier, when the cloning of an object with readonly required a workaround, this is now simplified with PHP 8.5. PhpStorm 2025.3 is now available at the JetBrains tool app, including the 30-day free license key.
